# Pebrel 2.1.0

## English

### Added

- **Built-in intelligent completion.** Discover candidates from Git branches and references, project scripts, SSH config aliases, registered WSL distributions on Windows, and the filesystem. Command arguments guide the suggestions, so first-use commands can complete without matching history or a shell completion plugin. Addresses [#353](https://github.com/Kuddev/pebrel/issues/353).
- **Three completion modes.** Choose Inline, List, or Hybrid in Settings. Inline accepts the suggestion with Tab; List uses arrow keys to select and Tab to insert; Hybrid uses Right arrow to accept the inline suggestion and Tab to open the list. Changes apply to open terminals.
- **Zellij launcher discovery.** Recognize Zellij in common Unix installation paths, including Homebrew locations. Addresses [#356](https://github.com/Kuddev/pebrel/issues/356).
- **SSH persistent-session picker.** On Android, browse existing sessions on the connected host and open a selected session through the existing SSH login and host-trust flow. Discovery runs alongside the terminal without writing listing commands into its output.
- **Shift+Tab in terminal shortcuts.** The Android shortcut bar and its narrow-screen overflow menu can send Shift+Tab to local terminals, SSH sessions, and connected desktop panes.

### Fixed

- **Completion starts from the actual working directory on macOS and Linux.** Command history refreshes after execution, and directory candidates follow the current terminal. Nested shells retain their scoped history when a directory channel is unavailable.
- **Stale or partial input no longer receives outdated completion edits.** Wait for complete terminal input echo and discard results from an older input line, directory, or session.
- **PowerShell SSH option values keep their argument boundaries.** Completion quotes attached config paths and jump-host values when PowerShell would otherwise split them, while preserving spaces and existing quotes in path completions.
- **Backup storage locations can be changed from the drawer.** The storage menu appears above the drawer and accepts mouse and keyboard selection. Addresses [#354](https://github.com/Kuddev/pebrel/issues/354).
- **Connections recover after a phone network change.** Android retires the old desktop connection and retries through the current network while retaining drafts and the paired computer identity. Desktop LAN recovery also keeps the selected network interface.
- **Task notifications retain their position across reconnects.** Android keeps the last observed task state and sequence, detects the latest available transition after reconnecting, and checks the desktop process identity when opening a notification.
- **Phone terminal rendering and copying preserve the visible content.** Desktop mirrors keep the desktop grid by default; fallback glyphs and TUI symbols fit their cells. Copying joins display-only wraps while preserving real line breaks and spaces.

### Improved

- **Git completion follows the current repository.** Use local branches, tags, remote references, and configured automatic tracking behavior. Repository metadata queries stay offline and run in the background.
- **More responsive completion while typing.** Filesystem scans run outside history locks, obsolete work is cancelled, and short-lived source caches avoid repeating unchanged queries. Inline and list suggestions share the same command and path rules.
- **Native Agent integration on macOS and Linux.** Connect local hook installation, removal, event delivery, and settings inspection through the shared integration policy. Unix packages include the matching hook helper, and macOS can discover Codex sessions from live terminal processes.
- **More desktop integrations on macOS and Linux.** Connect native tray actions, quick-terminal windows, login startup, folder-opening entry points, and terminal sounds. Wayland global shortcuts use the desktop portal.
- **Direct terminal selection on Android.** Local, SSH, and mirrored desktop terminals share cell-based selection, draggable handles, and copy/paste actions. The selected frame stays stable while new output arrives, including wide and combining characters.

## 中文

### 新增

- **自带智能补齐。** 从 Git 分支与引用、项目脚本、SSH 配置别名、Windows 已注册的 WSL 发行版，以及文件系统中获取候选，并根据命令参数提供建议。第一次输入命令也能补齐，无需相应的命令历史或 Shell 补齐插件。对应 [#353](https://github.com/Kuddev/pebrel/issues/353)。
- **三种补齐模式。** 设置中可选择行内、列表或混合补齐：行内用 Tab 接受灰字；列表用方向键选择、Tab 插入；混合用右方向键接受灰字、Tab 打开列表。切换后立即应用到已打开的终端。
- **Zellij 启动器发现。** 支持 Unix 常见安装路径和 Homebrew 路径中的 Zellij。对应 [#356](https://github.com/Kuddev/pebrel/issues/356)。
- **SSH 持久会话选择。** 在 Android 上浏览已连接主机中的现有会话，并通过已有的 SSH 登录与主机信任流程打开所选会话。查询与终端独立进行，不向终端画面插入列表命令。
- **终端快捷栏支持 Shift+Tab。** Android 快捷栏及窄屏下的更多菜单可向本地终端、SSH 会话和已连接的桌面窗格发送 Shift+Tab。

### 修复

- **macOS 与 Linux 补齐使用实际工作目录。** 命令执行后刷新历史，目录候选跟随当前终端；嵌套 Shell 没有目录通道时，保留当前作用域的历史补齐。
- **过期结果或不完整回显导致补齐位置错误。** 等待终端完整回显当前输入，并丢弃旧输入、旧目录或旧会话产生的补齐结果。
- **PowerShell 拆分 SSH 选项值。** 对需要保护的紧贴配置路径与跳板参数补上引号，保持参数边界；路径补齐同时保留空格和已有引号。
- **备份抽屉内无法切换存储位置。** 存储位置菜单正确显示在抽屉上方，支持鼠标和键盘选择。对应 [#354](https://github.com/Kuddev/pebrel/issues/354)。
- **手机换网后连接未恢复。** Android 释放旧桌面连接，使用当前网络重试，并保留输入草稿和已配对电脑身份；桌面局域网恢复同时保留选定的网卡。
- **重连后丢失任务通知进度。** Android 保留最后观察到的任务状态和序号，重连后识别最新可见的状态变化，点击通知时核对桌面进程身份。
- **手机终端画面与复制内容不一致。** 桌面镜像默认保留电脑端网格，回补字形与 TUI 符号正确落在单元格内；复制时合并仅用于显示的软换行，保留真实换行和空格。

### 改进

- **Git 补齐跟随当前仓库。** 支持本地分支、标签、远端引用和仓库配置中的自动跟踪行为；仓库信息查询在后台进行，无需联网。
- **连续输入时的补齐响应。** 文件扫描不再长时间占用历史锁，过期任务及时取消，短时缓存减少重复查询；行内与列表候选共用命令和路径规则。
- **macOS 与 Linux 原生 Agent 集成。** 接通本地 Hook 安装、移除、事件传递和设置检查，复用统一的集成策略。Unix 安装包附带对应的 Hook 辅助程序，macOS 可从运行中的终端进程发现 Codex 会话。
- **macOS 与 Linux 桌面集成。** 接通原生托盘操作、快速终端窗口、登录自启、打开目录入口和终端提示音；Wayland 全局快捷键使用桌面 Portal。
- **Android 直接选取终端内容。** 本地、SSH 和桌面镜像终端共用按单元格选取、拖动手柄与复制粘贴操作；新输出到来时保持选中画面稳定，并正确处理宽字符与组合字符。
